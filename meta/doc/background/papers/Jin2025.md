# A Survey on Knowledge Graph Evolution: Proliferation, Dynamic Embedding, and Versioning

- **Authors:** Xiongnan Jin, Zhilin Wang, Manni Duan, Yan Shao, Xingyun Hong, Yongheng Wang, and Byungkook Oh
- **Year:** 2025
- **Journal/Venue:** International Journal of Web and Grid Services
- **DOI/URL:** https://doi.org/10.1504/IJWGS.2025.10069835
- **BibTeX key:** Jin2025
- **Source:** PDF

## Key Contribution

Jin et al. survey knowledge graph evolution, covering KG proliferation, fact validation, property error detection, rule mining, dynamic embeddings, and versioning [@Jin2025].
The key relevance is that useful KGs are not static stores; they require continuous update, validation, embedding refresh, and version control.

## Methods

The paper reviews methods, evaluation metrics, datasets, experimental performance, and future directions for KG evolution.
It frames the topic in the era of LLMs, where KGs can support structured knowledge for LLM systems but must evolve with minimal human intervention.

## Key Findings

The survey identifies KG proliferation, dynamic embedding, and versioning as central parts of KG evolution [@Jin2025].
It highlights automated evolution techniques and the importance of fact validation and error detection.

## Relevance

Science needs graph versioning and update provenance.
Evidence updates, agent edits, paper batches, question renames, and task additions should be auditable graph evolution events.
LLM-assisted graph updates need validation status and rollback/replay semantics.

## Limitations

This is a broad survey, not a Science-specific implementation guide.
Dynamic embeddings can obscure provenance if treated as primary graph state.
The project should favor explicit graph evolution records before learned embedding views.
