# Pre-registration enforcement under single-agent authorship

## Summary

When a pre-registration record is authored by the same agent that subsequently executes the analysis, in a repository the researcher fully controls and with no externally verifiable timestamp, does pre-registration still prevent HARKing — and if not, what structural change would re-establish the temporal and social separation its mechanism depends on?

**Exploration rationale (one line per contributing lens):**

- _mechanism_: Pre-registration prevents HARKing through a specific causal mechanism: an externally verifiable temporal separation between hypothesis commitment and data analysis. That mechanism fails when the "pre" cannot be verified from outside the researcher's control, as with a file in the same editable repository authored and read by the same agent in one session. The toolkit ships a pre-registration skill without isolating the mechanism that makes it work.
- _contrarian_: Stated as a null: the pre-registration gate does not reduce HARKing or confirmation bias in single-researcher AI-assisted projects, because the researcher controls the content, the timing relative to results, and the post-hoc interpretive framing. The epistemic value the literature attributes to pre-registration derives from independent oversight conditions absent here, making the gate ceremony that can be satisfied retroactively.
