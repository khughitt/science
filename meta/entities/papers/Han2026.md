# BClean+: A Bayesian Data Cleaning System With Automated Prior Generation

- **Authors:** Ziyan Han, Jing Zhu, Jinbin Huang, Sifan Huang, Yaoshu Wang, Rui Mao, and Jianbin Qin
- **Year:** 2026
- **Journal:** IEEE Transactions on Knowledge and Data Engineering
- **DOI/URL:** https://doi.org/10.1109/TKDE.2026.3656941
- **BibTeX key:** Han2026
- **Source:** PDF

## Key Contribution

Han et al. introduce BClean+, a Bayesian data-cleaning system that automates prior generation using semantic type identification, LLM-derived format constraints, hierarchical Bayesian-network structure discovery, and a reusable template library [@Han2026].
For Science, the paper shows how data quality, priors, and probabilistic graph structure interact before downstream evidence can be trusted.

## Methods

BClean+ models dataset attributes as nodes in a Bayesian network and performs maximum-a-posteriori cell repair under learned dependencies and user constraints.
The system automates prior acquisition by sampling column contexts, using an LLM to identify semantic types, synthesizing format patterns as constraints, maintaining reusable templates, and optionally generating probabilistic programming code for systems such as PClean.
It also uses hierarchical structure discovery to group attributes into semantic modules and pruning strategies to reduce inference cost.

## Key Findings

The paper reports average F1 of 0.89 and up to 0.98 across real-world datasets, with average improvement of 0.42 over baselines and user configuration time reduced from hours to under five minutes.
Automated semantic constraints are the dominant contributor to performance in ablations.
The generated PPL programs can outperform or match expert-authored PClean programs in the reported evaluation.
The approach remains limited by cell-level focus, learned Bayesian-network quality, and a closed-domain repair assumption.

## Relevance

Science should treat data cleaning and data-quality inference as part of evidence provenance.
If an evidence update depends on a cleaned dataset, the graph should record cleaning model, prior-generation source, semantic constraints, validation status, and repair uncertainty.
BClean+ also suggests a pattern for Science tooling: LLMs can help propose structured priors or constraints, but the generated artifacts should become inspectable, reusable templates rather than hidden prompt outputs.

## Limitations

BClean+ mainly addresses cell-level syntactic and semantic errors, not aggregate numerical inconsistencies or systematic measurement bias.
Its repair quality depends on the learned Bayesian-network structure.
The closed-domain assumption limits correction of rare or unseen valid values.
The use of LLM-derived semantic labels introduces a provenance and validation requirement that the evidence graph should not hide.
