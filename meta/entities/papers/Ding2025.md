# SciToolAgent: A Knowledge Graph-Driven Scientific Agent for Multi-Tool Integration

- **Authors:** Keyan Ding, Jing Yu, Junjie Huang, Yuchen Yang, Qiang Zhang, and Huajun Chen
- **Year:** 2025
- **Journal/Venue:** arXiv
- **DOI/URL:** https://arxiv.org/abs/2507.20280
- **BibTeX key:** Ding2025
- **Source:** PDF

## Key Contribution

Ding et al. propose SciToolAgent, an LLM-powered scientific agent that uses a scientific tool knowledge graph for tool selection, tool orchestration, and safety checking [@Ding2025].
The core contribution is treating tool dependencies, prerequisites, compatibility, input/output formats, and safety levels as explicit graph state.

## Methods

SciToolAgent uses LLM roles for planning, execution, and summarization.
It retrieves over SciToolKG to generate chains of tools, executes them sequentially, checks safety against a safeguard database, and loops through summarization and replanning where needed.
The paper evaluates the agent on SciToolEval, a curated benchmark of scientific tool-use problems.

## Key Findings

The paper reports overall accuracy of 94% on SciToolEval and claims a 10% improvement over baselines [@Ding2025].
Case studies cover protein engineering, chemical reactivity prediction, chemical synthesis, and metal-organic framework screening.

## Relevance

This paper is directly relevant to Science's command and skill architecture.
Scientific agents need first-class tool graph state: tool capabilities, input/output schemas, compatibility, dependencies, safety constraints, execution provenance, and validation history.
This extends Q07 from "LLM agents as sources" to "LLM agents as graph-governed operators."

## Limitations

The paper is recent and benchmark details need independent inspection before relying on performance claims.
Tool safety is domain-specific and may not transfer directly.
Science should avoid treating a successful tool chain as validated scientific evidence without output-level validation.
