# Integrating Large Language Model for Improved Causal Discovery

- **Authors:** Taiyu Ban, Lyuzhou Chen, Derui Lyu, Xiangyu Wang, Qinrui Zhu, Qiang Tu, and Huanhuan Chen
- **Year:** arXiv 2023; accepted version lists IEEE Transactions on Artificial Intelligence DOI in 2025
- **Journal/Venue:** IEEE Transactions on Artificial Intelligence / arXiv
- **DOI/URL:** https://doi.org/10.1109/TAI.2025.3560927
- **BibTeX key:** Ban2023
- **Source:** PDF

## Key Contribution

Ban et al. propose an error-tolerant framework that uses LLM-derived causal knowledge as soft prior information for data-based causal structure learning [@Ban2023].
The key contribution is not treating the LLM as a causal oracle; it restricts LLM reasoning to clearer causal knowledge, translates statements into ancestral constraints, and balances priors against data fit.

## Methods

The framework derives variable metadata, extracts causal statements with constrained prompting, validates them through reasoning, converts them to positive ancestral constraints, and incorporates them softly into score-based structure learning.
The method is evaluated on eight real-world causal structures.

## Key Findings

The paper reports that LLM-derived priors improve data-based causal discovery across tested datasets while remaining robust to inaccurate priors [@Ban2023].
It argues that LLM causal statements often correspond to qualitative or indirect interactions, so encoding them as direct edges can be harmful.
Soft prior use is positioned as more robust than hard constraints.

## Limitations

The approach depends on LLM knowledge and prompt design.
The paper's accepted metadata differs from the original arXiv filename, so publication details should be rechecked before citation-sensitive use.
LLM priors may encode literature bias, cultural bias, or outdated consensus.
