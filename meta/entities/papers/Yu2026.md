# SciCUEval: A Comprehensive Dataset for Evaluating Scientific Context Understanding in Large Language Models

- **Authors:** Jing Yu, Yuqi Tang, Kehua Feng, Lei Liang, Qiang Zhang, Keyan Ding, and Huajun Chen
- **Year:** 2026
- **Journal/Venue:** Scientific Data
- **DOI/URL:** https://doi.org/10.1038/s41597-026-06594-9
- **BibTeX key:** Yu2026
- **Source:** PDF

## Key Contribution

Yu et al. introduce SciCUEval, a benchmark for evaluating scientific context understanding in LLMs across domains, modalities, question types, and reasoning competencies [@Yu2026].
It targets a key gap: scientific agents must identify relevant context, detect absent information, integrate multiple sources, and infer from context.

## Methods

SciCUEval includes ten domain-specific sub-datasets across biology, chemistry, physics, biomedicine, and materials science.
It uses unstructured text, structured tables, and semi-structured knowledge graphs.
It evaluates four competencies: relevant information identification, information-absence detection, multi-source information integration, and context-aware inference.

## Key Findings

The paper reports evaluations of state-of-the-art LLMs and provides fine-grained analysis of strengths and limitations in scientific context understanding [@Yu2026].
It positions SciCUEval as a standardized benchmark for scientific-domain LLM evaluation.

## Relevance

Science needs exactly these evaluation dimensions for LLM-generated paper summaries, graph updates, tool plans, and synthesis artifacts.
Information-absence detection is especially important: agents should know when the evidence payload cannot be populated or when a question cannot be answered from the provided sources.

## Limitations

Benchmark performance may not transfer to this project's exact paper-summary and graph-update workflows.
Dataset construction and model evaluations should be inspected before adopting metrics wholesale.
Science should create project-local evaluation slices using its own artifacts.
