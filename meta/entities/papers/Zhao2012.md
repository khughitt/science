# A Bayesian Approach to Discovering Truth from Conflicting Sources for Data Integration

- **Authors:** Bo Zhao, Benjamin I. P. Rubinstein, Jim Gemmell, and Jiawei Han
- **Year:** 2012
- **Journal:** Proceedings of the VLDB Endowment
- **DOI/URL:** https://doi.org/10.14778/2168651.2168656
- **BibTeX key:** Zhao2012
- **Source:** PDF

## Key Contribution

Zhao et al. introduce the Latent Truth Model, an unsupervised Bayesian graphical model for inferring both fact truth and source quality from conflicting data-integration records [@Zhao2012].
The central contribution is to model source quality as two independent dimensions, sensitivity for false negatives and specificity for false positives, rather than collapsing quality into precision or accuracy [@Zhao2012].
This two-sided quality model lets the method support multi-valued attributes, where several facts may be true for the same entity and omissions are not equivalent to false assertions [@Zhao2012].

## Methods

The input is a raw database of triples containing an entity, an attribute value, and a source, which the paper recasts into fact records and positive or negative source claims [@Zhao2012].
For a source that asserts some values for an entity but omits another candidate value for the same entity, the omitted value becomes a negative claim rather than missing evidence [@Zhao2012].
The model assigns each fact a latent Boolean truth variable and a prior truth probability drawn from a Beta distribution [@Zhao2012].
Each source receives a false-positive-rate parameter and a sensitivity parameter, both drawn from Beta priors so prior beliefs about source behavior can be incorporated [@Zhao2012].
Observed claims are generated from the source's false-positive rate when the fact is false and from the source's sensitivity when the fact is true [@Zhao2012].
Inference uses collapsed Gibbs sampling, integrating out the fact truth probabilities and source-quality parameters and sampling only latent fact truth labels [@Zhao2012].
The paper also describes source-quality MAP estimates and an incremental variant that reuses learned source quality as priors or as fixed medium-term quality estimates for new data [@Zhao2012].

## Key Findings

On the book-author dataset, LTM and its incremental variant achieved precision 1.000, recall 0.995, false-positive rate 0.000, accuracy 0.995, and F1 0.997 at threshold 0.5 [@Zhao2012].
On the movie-director dataset, LTM achieved precision 0.943, recall 0.908, false-positive rate 0.150, accuracy 0.892, and F1 0.925 at threshold 0.5 [@Zhao2012].
The incremental variant was nearly indistinguishable from batch LTM on reported accuracy and F1, supporting reuse of learned source-quality estimates for online truth prediction [@Zhao2012].
Methods that ignore negative claims, including TruthFinder, Investment, and LTMpos, became overly optimistic and predicted all facts as true in the reported threshold-0.5 experiments [@Zhao2012].
The strongest non-LTM baseline, 3-Estimates, benefited from negative claims but lost recall because scalar accuracy cannot distinguish conservative omissions from erroneous assertions [@Zhao2012].
The learned movie-source qualities showed that sensitivity and specificity do not necessarily correlate, with sources such as Fandango having low sensitivity and high specificity while IMDB had high sensitivity and lower specificity [@Zhao2012].
The sampler reached near-optimal accuracy after about 50 iterations in the movie-data convergence experiment and runtime scaled linearly with claim count with reported R2 = 0.9913 [@Zhao2012].

## Relevance

This paper is directly relevant to Science's evidence aggregation foundations because it treats evidence integration as joint inference over latent truth and source reliability, not as majority voting [@Zhao2012].
It provides a concrete pattern for representing evidence payloads with both positive assertions and informative omissions.
Its sensitivity-specificity split maps cleanly onto Science's need to encode bias and missingness separately from corroborating support.
The incremental variant is relevant to research-agent workflows where evidence arrives over time and existing source-quality beliefs should inform later graph updates without forcing full recomputation each time.
The method's use of prior distributions over truth and source quality is a useful precedent for continuous Bayesian beliefs attached to proposition and evidence nodes.

## Limitations

LTM assumes binary fact truth and binary claim observations, so real-valued measurements, graded matches, or continuous effect estimates require extensions [@Zhao2012].
The model assumes source quality is constant for one attribute type, although the discussion notes that quality may vary by attribute type or by entity cluster [@Zhao2012].
The method assumes reasonably high specificity and few adversarial sources, and the authors note that adversarial sources can distort inferred specificity for benign sources [@Zhao2012].
The construction of negative claims assumes that a source associated with an entity had an opportunity to assert the omitted fact, which may fail when coverage, extraction, or schema differences are unobserved.
The experiments use manually labeled subsets of 100 books and 100 movies, so large-scale label diversity and domain transfer remain limited in the reported evaluation [@Zhao2012].
The approach does not directly model source copying or dependence, which the related-work section identifies as an important separate factor in truth discovery [@Zhao2012].
