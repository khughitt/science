# Claim And Evidence Model

> **Superseded.** This page documents an older `claim` / `relation_claim`
> vocabulary. The canonical Science reasoning model is now
> [`docs/proposition-and-evidence-model.md`](proposition-and-evidence-model.md).

New documentation and workflows should use:

- `proposition` for the primary belief-bearing assertion.
- `observation` for concrete empirical findings.
- `evidence-line` for durable support or dispute linked to a proposition,
  hypothesis, or other epistemic target.
- `support` and `dispute` relations for evidence stance.

The old body is intentionally not repeated here because it contradicts the
current model and can mislead search-driven readers. Use the canonical
proposition/evidence model for field-level detail and migration guidance.
